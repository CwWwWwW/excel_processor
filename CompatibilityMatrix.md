# Compatibility Matrix

| OS | Runtime | Status |
| --- | --- | --- |
| Windows 7 SP1 x86 | legacy-x86 | script-required |
| Windows 7 SP1 x64 | legacy-x64 | script-required |
| Windows 8/8.1 x86 | legacy-x86 | script-required |
| Windows 8/8.1 x64 | legacy-x64 | script-required |
| Windows 10 32-bit | legacy-x86 | script-required |
| Windows 10 build <17763 x64 | legacy-x64 | script-required |
| Windows 10 build >=17763 x64 / Windows 11 | modern-x64 | script-required |

Excel 2007 is C-level legacy support; Excel 2010/2013 are B-level; Excel 2016+ are A-level when runtime capabilities are present.
