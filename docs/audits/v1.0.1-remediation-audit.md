# v1.0.1 Remediation Audit

Baseline: `origin/release/v1.0.1` at `84588323375780ac13633eb92c978a5524f9b3c6`. The `v1.0.1` tag pointed at the same commit and GitHub returned `404` for a formal Release by tag, so the erroneous remote tag was deleted before remediation.

| Severity | File / line at audit | Root cause | Modification | Test method | Status |
|---|---:|---|---|---|---|
| P0 | `scheduler/job_scheduler.py:54` | Scheduler instantiated `ExcelComEngine()` directly, so COM could run in the main process. | Scheduler now owns `ExcelWorkerPool`; COM commands route through worker IPC only. | `tests/unit/test_scheduler_worker_boundary.py`, worker IPC tests. | Remediated |
